# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

We are committed to a welcoming, harassment-free experience for everyone. Be kind, be
constructive, assume good faith.

Instances of unacceptable behavior may be reported to **nicolas@gogrow.dev**. All
reports are reviewed promptly and confidentially.
